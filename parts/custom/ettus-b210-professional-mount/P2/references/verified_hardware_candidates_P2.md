Catalog locknuts are reusable only a limited number of times, with decreasing retention. Use fresh locknuts for final installation after service-cycle testing; do not apply threadlocker to the nylon insert. Listed Class 10 nut / Class 10.9 washer capability must not be equated to the full capacity or installation preload of a Class 12.9 screw. The designed external joint load, controlled preload, washer bearing and aluminum female-thread capacity require their own checks.

For 243 cleaning, cure on actual passive/finished surfaces, optional activation and removal, use [Henkel's April 2025 TDS](https://datasheets.tdx.henkel.com/LOCTITE-243-en_GL.pdf) and the [P1 evidence register](../../references/research_sources.md#hardware-data-and-precautions). McMaster's generic 24-hour full-strength field is not a tested release schedule for this joint. Adhesive breakaway test torque is **not tightening torque**. No tightening torque is supplied here.

## Integration requirements

Per-orientation hardware counts were confirmed with the root engineering task and recorded in the final catalog BOM. Check the manufactured stack using actual washer thickness (0.9–1.1 mm), nut height (5 mm), coating, screw length tolerance, thread leads and selected fit shims. Check required complete thread engagement, recessed retainer tips, full nylon-ring engagement and specified protrusion of through bolts. Recheck tool corridors against these actual heads/nuts. Installed shim counts remain as required by measurement; initial shim purchase packs are selection inventory.
